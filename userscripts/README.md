## TamperMonkey userscripts

A collection of tiny userscripts adding quality-of-life fixes to DuelingBook.

### Installation instructions

1. Install the TamperMonkey extension. This extension allows you to run little scripts to customize the functionality of websites.
    * Firefox: https://addons.mozilla.org/en-CA/firefox/addon/tampermonkey/
    * Chrome: https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo
2. If you are on a Chrome-based browser, you will need to [enable user scripts](https://www.tampermonkey.net/faq.php?locale=en&q=Q209) to be able to run scripts on webpages.
3. Go to one of my userscripts (e.g. [`minimal-keyboard-shortcuts`](https://github.com/vivaria/db-userscripts/blob/main/userscripts/db.duel.keyboard-shortcuts.minimal.user.js) and click the "Raw" button.
    ![Raw button](https://i.imgur.com/tgpk2wa.png)
4. If TamperMonkey is installed correctly, it will automatically detect the script and ask you to install it.
    ![TamperMonkey install prompt](https://i.imgur.com/pXpi5Ku.png)
5. Refresh DuelingBook, and the script should start working.

Enjoy! :)
